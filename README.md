Postman-коллекция для работы с http-сервисом, реализованным на расширении SLОбменССайтом версии 3.0.9.4

API для взаимодействия с 1С Управление Компанией для Молдовы
Root URL:
http://{serverAdress}/{baseName}/hs/site-exchange/{exchandeID}/{method}
serverAdress
baseName - имя публикации
exchandeID - идентификатор настройки обмена в 1C
История изменений

Версия 1.0 - 2026.04.02

Заметки:
Обмен может быть настроен на получение всех данных, либо только изменений, тогда в пакете данных будет заполнен параметр messageNo*
  *После чтения данных на стороне сайта требуется оповестить 1С о завершении приема (метод confirm с передачей номера сообщения).
Режим иерархии может быть выбран на стороне 1С: группы, категории или произвольная иерархия (настраивается вручную)
Остатки выгружаются по всем складам, либо только по тем, что указаны в отборе
Возможна детализация товаров по характеристикам (тогда сам товар считается мастер-товаров), если это настроено в учетной системе, например
товар "iPad Air 11", характеристики: "128GB", "256GB". Цены и остатки в таком случае выгружаются в разрезе характеристик

Для обновления статуса заказа на сайте поддерживается webhook. Для этого в настройках обмена следует указать полный адрес скрипта на сайте и API ключ для отправки в запросе. Пример отправляемого запроса:
  curl --request POST
  "https://mysite.md/order-status"
  --header "Content-Type: application/json"
  --header "Accept: application/json"
  --data "{
  "id": "123456",
  "api_key": "861b9d827417dec90"
  }"
